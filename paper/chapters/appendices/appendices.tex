\section{Software and Hardware Environment}
\label{app:environment}

All experiments were conducted on a single workstation with the following specifications:

\begin{itemize}
    \item \textbf{CPU}: AMD Ryzen 5 5600X (6 cores, 12 threads)
    \item \textbf{GPU}: NVIDIA GeForce RTX 3060 (12 GB GDDR6)
    \item \textbf{RAM}: 32 GB DDR4-3200
    \item \textbf{OS}: Windows 11 Pro (build 26200)
    \item \textbf{Python}: 3.11.8
    \item \textbf{PyTorch}: 2.6.0+cu126
    \item \textbf{CUDA}: 12.6
    \item \textbf{Key packages}: NumPy 1.26, pandas 2.1, scikit-learn 1.4, matplotlib 3.8, networkx 3.2
\end{itemize}

The complete source code, training scripts, and model weights will be released upon acceptance to facilitate reproducibility.

\section{System Interface Screenshots}
\label{sec:ui-screenshots}

The deployed system provides three interfaces for different operational roles. The command centre dashboard (Figure~\ref{Fig.ui_command}) serves as the primary monitoring interface for network operations managers, aggregating predictions across all 374 stations and highlighting stations where predicted ridership exceeds configurable thresholds. The live station map (Figure~\ref{Fig.ui_map}) provides a geospatial view of the Astana bus network, colour-coding each station by predicted demand intensity. The depot operations interface (Figure~\ref{Fig.ui_depot}) targets fleet managers responsible for vehicle assignment and route scheduling. The Streamlit station forecast view (Figure~\ref{Fig.streamlit_forecast}) shows predicted boarding counts with Negative Binomial confidence intervals across the four prediction horizons. The live simulation panel (Figure~\ref{Fig.streamlit_validation}) supports model validation by overlaying real-time observations against predictions.
